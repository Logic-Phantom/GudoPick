### Data Safety 양식 초안 (소유자 검토 필수)

ML Kit SDK가 Google로 보내는 데이터가 있으므로 "데이터를 수집하지 않음"으로 단정하지 않는다.
SDK가 수집하는 데이터도 앱의 수집으로 신고해야 하는지에 대한 Play의 기준을 양식 작성 시 확인한다.

| 질문 | 초안 | 근거 |
|---|---|---|
| 사용자 데이터를 수집/공유하나요? | 수집: 예(SDK 진단 데이터) / 공유(제3자 이전): 아니요 | ML Kit 공개 페이지: 기기·앱 정보, 설치당 식별자, 성능 지표 등을 Google이 진단·사용 분석에 사용. 제3자 전송 없음 |
| 데이터 유형 후보 | 기기 또는 기타 ID(설치당 식별자), 앱 정보 및 성능(진단), 앱 활동(기능 이벤트) — Play 데이터 유형 가이드로 최종 분류 | 같은 문서 |
| 사진·동영상 | 수집 안 함 | 프레임·사진은 기기 밖으로 나가지 않음(ML Kit 약관 + 앱 코드) |
| 위치, 연락처, 금융, 건강, 메시지 | 수집 안 함 | 권한·코드 없음 |
| 전송 중 암호화 | 예 | ML Kit는 HTTPS 사용(공개 페이지) |
| 삭제 요청 방법 | 계정 없음. 앱 내 데이터 초기화/앱 삭제 | |
| object-detection의 Firebase Remote Config / Installations | 해당 Firebase 공개 페이지 항목을 추가 반영 | ML Kit 공개 페이지가 참조 — **Firebase 페이지는 이번에 읽지 않음 [미확인]** |

## 스토어 공개 자료 초안

- 앱 이름: **구도픽** / 영문: **GudoPick**
- 패키지/번들 ID 후보: `app.gudopick.mobile` (사용 가능 여부 소유자 확인)
- 짧은 설명(초안): `내 취향으로 맞추는 실시간 구도 가이드 카메라`
- 자세한 설명(초안)

  > 구도픽은 내가 고른 취향을 카메라 가이드로 바꿔 주는 구도 코치 카메라예요.
  >
  > - 취향 선택: 찍는 대상, 구도, 피사체 위치·크기, 비율을 고르면 나만의 프리셋이 만들어져요.
  > - 실시간 가이드: 인물은 얼굴, 음식·사물은 주요 피사체의 위치와 크기를 기기 안에서 확인해 목표 위치와 비교하고 짧은 문구로 안내해요.
  > - 비율 프레임(1:1, 4:5, 3:4, 9:16), 3분할·중앙 격자, 센서 기반 수평 안내
  > - 구도가 맞고 안정되면 화면과 진동으로 알려줘요. 촬영은 직접 셔터를 눌러요.
  > - 촬영 결과를 확인한 뒤 "저장하기"를 눌렀을 때만 사진 앱에 저장돼요.
  > - 계정·서버 없이 동작하고, 카메라 화면과 사진을 서버로 보내지 않아요.
  >
  > 안내는 참고용이며 촬영 결과를 보장하지 않아요. 풍경 모드는 수평과 격자 안내를 제공하고, OOTD 모드는 얼굴 위치 기준의 기본 프레이밍 안내를 제공해요.

- 쓰지 말아야 할 표현: 얼굴 인식, AI 자동 촬영, 전신/포즈 분석, 지평선 인식, "완벽한 사진 보장", "완전 오프라인", "데이터 수집 없음".
  - 앱 화면의 목업 문구 "완벽한 구도", "가장 좋은 구도로"는 D-024에 따라 유지했지만 **스토어 설명에는 사용하지 않는 것을 권장**(소유자 결정).
- 아이콘: 자체 제작(뷰파인더 브래킷 + 라임 스파클). `assets/brand/icon.png`
- 스크린샷: 실제 기기 화면에서 캡처해야 한다. **아직 없음**(실기기 미실행).
